
```
Клиент
1 Session получает запрос
2 Parser разбирает запрос
3 RequestHandler определяет event
4 нужный Model выполняет SQL через SQLiteCpp
5 shop.db
6 результат возвращается клиенту
```
Модели:

1`UserModel` отвечает за регист и аутенф

Что делают методы:

- `registerUser()`  проверяет логин и добавляет пользователя
- `authorizeUser()` проверяет логин и пароль, создаёт и сохраняет токен
- `isTokenValid()`  проверяет наличие токена

2 `ProductModel`
Отвечает за таблицу `products`
методы её:
- взаимодействие с `PRODUCT_LIST`
- поиска товара при покупке
- проверки остатка
- уменьшения количества товара

3`PurchaseModel`
Отвечает за таблицу `purchases`

Она используется для:
- `PURCHASE_CREATE`
- `PURCHASE_LIST`
- записи совершённой покупки
- получения покупок конкретного пользователя

4`ShopDatabase`
класс отвечает за открытое соединение с `shop.db`
Он создаётся один раз при запуске сервера
